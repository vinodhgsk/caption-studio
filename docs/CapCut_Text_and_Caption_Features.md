# CapCut — Complete Text & Caption Features

A consolidated reference of every text, caption, decoration, effect, transition, and animation feature in CapCut, with both **predefined presets** and **custom options** noted throughout.

---

## 🌐 Language & Script Support (this build)

This build is **Indic-first**. It officially supports six languages — **Tamil (primary), Telugu, Malayalam, Kannada, Hindi, English** — across fonts, auto-caption, styles, animation, translation, TTS, and export:

- Complex-script shaping (matras, conjuncts, reordering) for Tamil/Telugu/Malayalam/Kannada/Devanagari, plus Latin for English
- Grapheme-cluster-aware reveal / typewriter / per-character animation and line wrapping
- Indic-capable bundled fonts with a per-script fallback chain; Tamil is the global default
- Language detection / translation / TTS restricted to these six (Tamil default)
- **Transliteration** — convert text between scripts, any supported language to any other (script/phonetic, not meaning); includes Romanized typing → Indic script

## 🎬 Text Animations — Reveal Effects (Kinetic / Composite)

Mask-, sweep-, and border-driven reveals that go beyond the basic In presets. Each is a preset with adjustable parameters (unit, direction, duration, easing + effect-specific sliders).

| Preset | Description |
|---|---|
| Frame | Animated border/box draws around the text, then reveals it |
| Swipe | A color bar sweeps across, revealing text in its wake |
| Type | Typewriter character reveal with a blinking caret |
| Slide | Masked directional slide-in (clipped to the text box) |
| Glossy | A glossy sheen / light glint sweeps across the letters |
| Appear by | Staggered reveal by character, word, or line |
| Stomp | Words slam in big-to-small with an impact settle (beat-friendly) |
| Stripe | Diagonal stripe bars wipe across to reveal the text |
| Curtain | Text revealed by a curtain-style mask opening |

*Custom: per-effect parameter sliders + duration/speed.*

## 📍 Caption-Specific Preset Styles

- Built-in caption template library: **Karaoke Highlight, Pop by Word, Bounce, Typewriter, TikTok Classic**, and more — one click applies the style to the entire caption track
- Word-by-word reveal (each word appears as spoken)
- Bold white + black outline (high-contrast viral style)
- Yellow keyword highlight style (educational / business)
- Animated word highlight (active word changes color as audio plays)
- Sound effect captions (e.g. `[applause]`, `[music]`) as bracketed cues
- Lower thirds style presets
- Title card presets (Game, Technology, Sports, Trending categories)

---

## ⌨️ Keyframe & Motion

- Keyframe animation (desktop) — set position, scale, rotation, and opacity at any point on the timeline
- Custom motion path drawing
- AI Motion Tracking — text sticks to a moving face, hand, or object in footage
- Beat-sync — snap text appearance / disappearance to audio beats

---

## 🤖 AI Text Tools

- Auto Captions — speech-to-text in 130+ languages with automatic timing
- Language detection (auto-identify spoken language)
- Caption translation to target languages (inline on the same track)
- Transliteration — convert between scripts, any supported language to any other (e.g. Tamil ↔ Latin ↔ Devanagari ↔ Telugu); script/phonetic, not meaning; includes Romanized typing → Indic script
- Keyword color highlighting — AI detects emphasis words
- Text-to-Speech (269 voices) — generate a voiceover from any text layer
- AI font generator from text prompt
- Remove Silence — strips filler sounds from auto-captioned timelines

---

## 📤 Export & Output

- Burn-in captions (permanently baked into video)
- SRT export (Pro / Team)
- VTT export (Pro / Team)
- ASS subtitle file export (Pro / Team)
- Caption length limit: 10 min/project on Free, unlimited on Pro / Team

---

## 💾 Saving Custom Presets

- Save a customized text style (font, color, stroke, shadow, animation) as a **reusable preset** to keep a consistent look across videos
- Import community / third-party preset packs (kinetic titles, subtitle styles, overlay sets)
- Presets are format-specific — choose 9:16, 16:9, or square to avoid cropping
